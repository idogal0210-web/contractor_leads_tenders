# Contractor Leads Tenders - Core API & Config

This repository contains the barebones configuration and API connections for the contractor leads and tenders project.

## Project Structure
- `config/` - Contains API settings, environment configurations, and the contractor profile.
- `.env` - Environment variables and API keys (local only).
- `.agents/skills/` - Custom agent skills (e.g., save-and-sync).
- `requirements.txt` - Project dependencies.
